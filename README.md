# 个人写作习惯与研究偏好

💡 **一套系统化的个人写作、研究和交流偏好规范**

## 📖 项目简介

本项目记录个人在学术写作、研究交流和文献阅读中的习惯与偏好。涵盖论文撰写、学术报告、研究笔记、批判性阅读等多个场景，提供一致的指导原则和具体操作规范。

**适用场景：**
- 📄 论文撰写与审阅（含正文、摘要、相关工作、翻译、润色）
- 📋 研究笔记与报告（含组会报告、课堂报告、幻灯片、演讲稿）
- 🔍 研究分析与批评（含文献调研、概念解释、方向分类、批判性阅读）

## 🎯 核心原则

### 1. **精准定义与范围**
   - 先弄清任务定义、关键概念和相互关系
   - 标题准确表达内容，不强行并列不同层级的概念

### 2. **具体、简洁、易懂**
   - 回答具体有力，避免不必要的扩展
   - 简洁不能以牺牲关键机制为代价

### 3. **独立判断与讨论**
   - 保持独立判断，不同意时说明依据并比较方案
   - 认真讨论，但不为迎合而放弃有依据的判断

### 4. **直接、干净的语言**
   - 避免防御性写作、迂回立论、术语堆砌和复杂长句
   - 每句话推进观点：提供证据、解释机制、说明差异或建立过渡

### 5. **分层对象与标准**
   - 论文面向专家，避免科普式铺垫
   - 严格比较主张与证据，正式写作只处理实质性错误

## ⚙️ 使用方式

1. **明确当前任务类型** — 是论文写作、报告演讲还是研究分析？
2. **查阅对应规范** — 根据任务类型读取相应参考文档
3. **优先应用用户要求** — 当前需求优先于默认偏好
4. **灵活组合** — 混合任务可以组合读取，但不要混淆使用场景
