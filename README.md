# 个人写作习惯与研究偏好

💡 **一套持续更新的个人写作、研究和交流偏好规范**

## 📖 项目简介

这是一个西电研究生在长期遭受论文写作、组会汇报和 PPT 制作折磨之后，逐渐整理出来的个人习惯 skill。它记录我在学术写作、研究交流和文献阅读中的偏好，并会随着新的任务和经验持续更新。

这个 skill 主要服务于以下场景：

- 论文撰写、修改与审阅
- 组会汇报、研究报告与演讲稿
- PPT 内容组织与表达
- 研究笔记、文献阅读与概念分析

## ✍️ Skill 风格

- 直接、简洁，不绕弯子
- 先明确概念、边界和任务目标
- 重视逻辑、证据和论证关系
- 保持独立判断，不一味迎合
- 避免套话、重复和不必要的术语堆砌
- 论文面向专家，报告和解释根据使用场景调整表达
- 让每句话都服务于观点、证据、机制或必要的过渡

## ⚙️ 使用原则

1. 先识别当前任务属于论文写作、报告汇报还是研究分析。
2. 根据任务类型读取对应的参考规范。
3. 用户当前的明确要求优先于默认偏好。
4. 区分长期习惯和单次任务限制，不把临时要求写成通用规则。

## 🔄 维护方针

共同偏好放在 [SKILL.md](SKILL.md)，具体操作规范放在对应参考文件中。这个项目没有追求一次完成，而是希望在一次次论文、汇报和 PPT 的折磨中持续迭代，逐渐形成更适合自己的工作方式。
